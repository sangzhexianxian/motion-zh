# 财经解读 · 竖屏信息卡

一条财经信息 → 24 秒竖屏片。封面、数据、方向、收尾四个镜头，深色科技底。

**1080×1920 / 30fps / 24 秒 / 中文 / 无外部依赖 / 不联网 / MIT**

这是一个 `.motion` 模板的源码目录。打包后是一个文件，交给 AI 助手就能出片。

## 它解决什么

中文财经解读最怕两件事：字数一多就挤爆画面；每个号做出来的样式都不一样，系列做不出统一感。

这个模板把两件事都钉死了：**每个文字槽位都有中文字符上限**（写进 `params.schema.json`，不是靠自觉），**版式和动效是代码**（不是参考视频）。同一套参数，跑一百遍都是一样的。

## 参数（这就是你唯一要改的东西）

| 字段 | 说明 | 上限 |
|---|---|---|
| `title` | 封面主标题 | 24 字 / 2 行 |
| `stats[]` | 关键数字 1–2 条 | value 8 字符、label 14 字 |
| `directions[]` | 方向 1–3 条 | 每条 16 字、单行 |
| `summary` | 收尾一句 | 20 字 |
| `brand` / `issue` / `date` / `cta` | 栏目名 / 期号 / 日期 / 引导 | 8 / 12 / 12 / 12 字 |

超了会被 `scripts/check_zh.py` 拦下来。**改文案，不要缩字号。**

## 怎么跑

```bash
# 1. 校验文案放不放得下
python3 scripts/check_zh.py --params presets/demo.json --schema params.schema.json

# 2. 抽帧看排版
node tools/render_probe.js

# 3. 打包成 .motion
node <motiongit-skill>/scripts/motion.mjs pack . out/finance-cards.motion
```

渲染接口只有三个全局：`window.MP`（参数）、`window.SEEK(t)`（定格到第 t 秒）、`window.DURATION`。

## 镜头表

| 镜头 | 时间 | 内容 |
|---|---|---|
| S1 | 0 – 4.2s | 品牌 chip、主标题（自适应 + 中文禁则断行）、日期 |
| S2 | 4.2 – 12.2s | 两张数据卡，间隔 1.9s 依次入场，底部扫光条 |
| S3 | 12.2 – 19.6s | 三条方向，逐条左滑，圆形序号 |
| S4 | 19.6 – 24s | 品牌行、总结句、CTA、大号品牌水印、日期期号 |

## 不是给谁用的

- 需要真人出镜口播 → 用带 presenter 口的模板
- 需要复杂图表曲线 → 本模板只有数据大字卡
- 超过三条并列要点 → 拆成两期
- 需要引用长段原文 → 信息卡不是文章

## 合规

不写收益承诺、不写涨跌点位；示例数字必须标「（示例）」。
