# 字幕卡片 · 逐句上屏

**把一份 SRT 直接变成竖屏片，不改你一个字。**

1080×1920 · 30fps · 时长由字幕决定 · MIT

---

## 它解决的那个具体问题

平台上几乎所有模板都要你「填结构化文案」——标题、三个要点、一句总结。

但真实工作流不是这样的。**你手上最先有的，是字幕。**

录完口播 → ASR 转写 → 得到一份 SRT。然后你要为了套模板，把字幕重新拆成标题和要点，改得面目全非。

这个模板跳过那一步：**把 SRT 丢进去，字幕本身就是画面。**

## 出来是什么样

- 每句字幕居中上屏，**逐字高亮**（读到的字亮起，没读到的留白）
- `keywords` 里指定的词命中后换色（数字、结论、病名）
- 顶部常驻栏目名 + 期号 + 时间进度条
- 上一句缩成小字留在上方，画面不空
- 底部显示「第 n / N 句」+ 时间码
- 单条字幕超过 36 字，按标点**自动切成两屏**——不改原文、不缩字号

## 中文排版做了三件事

| 问题 | 处理 |
|---|---|
| 标点跑到行首 | 禁则：`，。、；：？！）】》」』` 不出现在行首，行尾不放开括号 |
| 末行只剩一个字 | 孤字回退：末行 1 个字，从上一行挪一个字下来 |
| 长句缩字号看不清 | 不缩字到看不清，超过容量就切屏 |

字体用系统 Noto Sans CJK SC（回退 PingFang SC / 微软雅黑）。**模板不含字体文件**，渲染机器要有中文字体。

## 怎么用

```json
{
  "srt": "1\n00:00:00,000 --> 00:00:04,440\n李医生，我每天上班都累得不行\n\n2\n...",
  "brand": "李医生话健康",
  "issue": "气血 · 第 1 讲",
  "keywords": ["气血暗耗", "三个要点"]
}
```

交给 AI 助手，说一句「用这个模板把字幕做成竖屏片」。

## 参数

| 字段 | 必填 | 说明 |
|---|---|---|
| `srt` | 二选一 | SRT 原文，整段粘贴。**推荐这种** |
| `subtitles` | 二选一 | 结构化数组 `[{start, end, text}]` |
| `brand` | | 栏目名 ≤8 字，左上角 |
| `issue` | | 期号 ≤12 字，右上角 |
| `title` | | 顶部小标题 ≤24 字，**不占时间轴** |
| `keywords` | | 强调词 ≤12 个，命中换色 |
| `accent` | | 已读文字色，默认 `#F2C24E` |
| `accent2` | | 关键词色，默认 `#4CC2FF` |
| `tailSeconds` | | 片尾留白，默认 0.8 秒 |

## 时长

`durationPolicy: fit-content` —— **总时长 = 最后一句结束时间 + `tailSeconds`**。

没有「时长」参数，故意的：时长必须跟字幕对齐，否则音画会错位。

## 它不做什么

- **不出音轨**：只出画面，配音请在剪辑软件里把原音轨合上
- **不做图表、数据卡、章节卡**：那是信息卡类模板的活
- **不改字幕文字**：包括错别字和口语病句，要改请在源文件改
